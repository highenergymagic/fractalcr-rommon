# Security policy

This component is part of FractalCR, a development preview from Fractal
Microsystems. There are no production-supported release versions yet.

Use [private vulnerability reporting](https://github.com/highenergymagic/fractalcr-rommon/security/advisories/new)
for security findings. Include affected commits or image hashes, impact and
reproduction steps, with credentials and private data removed. Do not disclose
vulnerabilities in public issues. No response-time guarantee is offered.

For cross-component findings, use the [integration repository's private report form](https://github.com/highenergymagic/fractalcr/security/advisories/new).
See the [project security policy](https://github.com/highenergymagic/fractalcr/blob/main/SECURITY.md)
and [development status](https://github.com/highenergymagic/fractalcr/blob/main/docs/development-status.md)
for trust boundaries, known limitations and release gates.
